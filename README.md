# סטודיו וידאו

אפליקציית Android בעברית, עם minSdk 16 (Android 4.1 ומעלה).

## מה כלול בגרסה הראשונה
- ממשק עברי וידידותי.
- בחירת תמונות מהמכשיר ותצוגה מקדימה.
- פתיחת סרטון קיים וניגונו.
- מסך להזנת Gemini API key.
- שליחת בקשת יצירת וידאו ל-Gemini Interactions API עם מודל Gemini Omni Flash.
- GitHub Actions לבניית APK ולהעלאתו כ-Artifact.

## הגדרת Gemini
1. צור מפתח API ב-Google AI Studio.
2. פתח באפליקציה "הגדרות Gemini" והדבק את המפתח.
3. כתוב תיאור לסרטון ושלח בקשה.

המפתח נשמר בהעדפות הפרטיות המקומיות של האפליקציה. אין להעלות מפתח API לקוד המקור או ל-GitHub.

## מגבלות הגרסה
זהו שלב ראשוני. הממשק שולח בקשת יצירה ל-API, אך טיפול מלא בתהליך יצירה ארוך, הורדת קובץ הווידאו, הצגתו ושמירתו בגלריה עדיין דורשים השלמה ובדיקות מול חשבון Gemini פעיל. זמינות המודל, תמחור והרשאות תלויים בחשבון וב-Google API. Android 4.1.2 ישן מאוד, ולכן נדרשות בדיקות על המכשיר עצמו.

## בניית APK
ב-GitHub פתח Actions, בחר Build Android APK והפעל Run workflow. לאחר סיום מוצלח, הורד את ה-artifact בשם `video-studio-debug-apk`.
