# סטודיו וידאו – Gemini

אפליקציית Android בעברית, עם תמיכה החל מ-Android 4.1 (API 16).

## יכולות בגרסה זו
- ממשק עברי מעוצב ונוח.
- בחירת תמונות והצגתן בתצוגה מקדימה.
- פתיחת סרטונים קיימים וניגונם.
- יצירת קליפ וידאו מתיאור טקסטואלי באמצעות Gemini Omni דרך Interactions API.
- בחירת פורמט רחב (16:9) או אנכי (9:16).
- שמירת MP4 בתיקיית Movies במכשיר והפעלתו מתוך האפליקציה.
- GitHub Actions לבניית APK.

## חיבור Gemini
1. צור מפתח Gemini API ב-Google AI Studio.
2. פתח באפליקציה 'הגדרת מפתח Gemini' והדבק את המפתח.
3. כתוב תיאור, בחר יחס מסך ולחץ 'צור לי סרטון'.

יצירת וידאו דורשת מודל זמין בחשבון, חיבור לאינטרנט וזכאות/חיוב מתאימים. המפתח נשמר בהעדפות המקומיות של האפליקציה. אל תשתף אותו.

## בניית APK
ב-GitHub פתח Actions ובחר Build Android APK. לאחר ריצת workflow מוצלחת, הורד את ה-artifact בשם video-studio-debug-apk.

## תאימות והגבלות
- minSdk 16 כדי להתקין על Android 4.1.2.
- גרסה ראשונית: העורך מציג תמונות ומנגן סרטונים; הוא עדיין אינו כולל ציר זמן, חיתוך קליפים, מעברים או יצוא מצגת תמונות.
- איכות/זמן יצירת הווידאו תלויים בשירות Gemini ובמכסת החשבון.
