# סטודיו וידאו

אפליקציית Android בעברית, עם minSdk 16 (Android 4.1 ומעלה).

## מה כלול בגרסה הראשונה
- ממשק עברי וידידותי.
- בחירת תמונות מהמכשיר ותצוגה מקדימה.
- פתיחת סרטון קיים וניגונו.
- מסך הגדרות לכתובת API ומפתח של שירות יצירת וידאו ב-AI.
- שליחת תיאור הסרטון לשירות API מוגדר.
- GitHub Actions לבניית APK ולהעלאתו כ-Artifact.

## חשוב לדעת
החיבור ל-AI הוא מתאם בסיסי ששולח POST JSON בפורמט `{"prompt":"..."}`. ספקים שונים דורשים פורמט, אימות, מעקב משימה והורדת תוצאה שונים; לכן יש להתאים את החיבור לספק שבחרת. אין כאן עדיין מנוע מקומי לייצוא סרטון מתמונות. Android 4.1.2 ישן מאוד, וחלק מספריות עריכת הווידאו המודרניות אינן תומכות בו.

## בניית APK
ב-GitHub פתח Actions, בחר Build Android APK והפעל Run workflow. לאחר סיום מוצלח, הורד את ה-artifact בשם `video-studio-debug-apk`.
